About this prototype

    
SIH26070 — AI-based tropical cyclone detection, classification & short-term prediction.

  

    

      
What this is

      
A working front-end prototype of the system described in our problem
      statement. It demonstrates the complete workflow — multi-source ingest → preprocessing →
      time/location alignment → fusion → feature extraction → detection → classification →
      short-term prediction → map, charts and alerts — as one interface.

      
It is a prototype, not an operational forecast system. Model outputs shown here are
      simulated from historical cyclone behaviour so the interface and workflow can be evaluated
      before the trained models are wired in. No live satellite downlink is connected.

      
The goal, as in our deck, is not to replace meteorologists but to give them AI-assisted
      monitoring and analysis in one place.
